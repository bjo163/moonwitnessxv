# Security policy

## Reporting a vulnerability

Please do not report suspected vulnerabilities, credentials, exploit details, or private user data in a public Issue or pull request.

GitHub's private vulnerability reporting endpoint reported **disabled** for this repository on 26 October 2026. Until the owner enables it or publishes a private security contact, do not post vulnerability details publicly; contact the repository owner privately to arrange a secure reporting channel. No private reporting address or response-time commitment is published in this repository.

Include the affected commit or version, the relevant component, the impact you observed, and safe reproduction steps. Redact credentials, personal data, private witness content, and source material that is not approved for publication. Do not test against systems or data you do not own or have permission to assess.

## Supported versions

No released versions are currently listed. For a report about current repository code, include the exact commit SHA and affected path so maintainers can determine scope.

## Repository security information

The technical security and privacy boundaries are documented in [docs/architecture/SECURITY.md](docs/architecture/SECURITY.md). This policy describes disclosure handling; it does not certify the security of any application, deployment, or release.
