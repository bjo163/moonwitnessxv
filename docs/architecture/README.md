# Focused architecture contracts
These complement [BLUEPRINT](../../BLUEPRINT.md), not competing blueprints. [App/runtime ownership](APPS.md), [ORBIT spatial frontend](ORBIT.md), [SKYLINK communication surface](SKYLINK.md), [ECHOLOG storage surface](ECHOLOG.md), [id/en localization](I18N.md), [App Factory](FACTORY.md), [Publication/security](SECURITY.md), [Release/Coolify](RELEASE.md). D18 is accepted for SKYLINK and D19 for ECHOLOG. SKYLINK's REST/WebSocket control plane and provider adapters exist; ARSY integration/operator UI/end-to-end gates remain open. ECHOLOG has content-addressed filesystem storage and a bounded S3-compatible subset; consumer/operator UI/end-to-end gates remain open. ORBIT is an accepted planned frontend boundary under ADR-0004/M40, not a backend or domain owner. Code/test evidence and [TODO](../../TODO.md) remain authoritative.
