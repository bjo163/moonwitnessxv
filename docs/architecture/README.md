# Focused architecture contracts
These complement [BLUEPRINT](../../BLUEPRINT.md), not competing blueprints. [App/runtime ownership](APPS.md), [ORBIT spatial frontend](ORBIT.md), [LUMEN agent runtime](LUMEN.md), [SKYLINK communication surface](SKYLINK.md), [ECHOLOG storage surface](ECHOLOG.md), [ISP & Network Operations](ISP_NETWORK.md), [id/en localization](I18N.md), [App Factory](FACTORY.md), [Publication/security](SECURITY.md), [Release/Coolify](RELEASE.md). D18 is accepted for SKYLINK, D19 for ECHOLOG, and D20 for ISP/network operations through ARSY/MoonQL. SKYLINK's REST/WebSocket control plane and provider adapters exist; ARSY integration/operator UI/end-to-end gates remain open. ECHOLOG has content-addressed filesystem storage and a bounded S3-compatible subset; consumer/operator UI/end-to-end gates remain open. D20 implementation remains under M51. ORBIT is an accepted planned frontend boundary under ADR-0004/M40, not a backend or domain owner. LUMEN under ADR-0010/M41 is an accepted framework/worker architecture boundary, not implementation evidence. Code/test evidence and [TODO](../../TODO.md) remain authoritative.
