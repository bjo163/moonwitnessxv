# M00-02 — Fastify Hub Routes, MoonQL Addons, and Module Collision Matrix

- **Audit Date**: 2026-10-26
- **Target Backend**: `apps/radio` (Target ARSY Hub)
- **API Base Prefix**: `/api/v1`

---

## 1. Top-Level Service Index
- `GET /` — Service Index (metadata deskriptif, endpoint health, metrics, studio, docs).
- `GET /docs` — Swagger UI OpenAPI Documentation.
- `GET /docs/json` — OpenAPI JSON Schema.

---

## 2. Handwritten Route Modules (`apps/radio/src/modules/`)
Modul ini dilindungi guard collision agar tidak tertimpa oleh autogenerated REST model.

| Module Path | HTTP Methods & Routes | Auth Policy | Description |
|---|---|---|---|
| `health` | `GET /api/v1/health` | Public (Anonymous) | Service health check & uptime |
| `metrics` | `GET /api/v1/metrics` | Admin / Token | Prometheus metrics text format |
| `studio` | `GET /api/v1/studio` | Admin Session | Embedded MoonQL Studio Admin UI |
| `channels` | `GET /api/v1/channels`<br>`POST /api/v1/channels/:id/send` | Admin | Outbound communication channel registry |
| `announcer` | `POST /api/v1/announcer/request` | Public / Rate-limited | Listener track request & announcement |
| `denpa` | `POST /api/v1/denpa/transmit` | Webhook Secret / HMAC | Inbound transmission receiver |
