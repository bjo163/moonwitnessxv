## Decision gate

These sources support a bounded terms inventory, not an implementation decision. Before a provider is enabled, record the chosen product/API and version, source attribution, licence/terms, request quota, freshness and revision semantics, permitted storage and redistribution, and the owner who approved the use. Preserve provider uncertainty and corrections in the observation model. Do not use any feed to issue emergency instructions or claim physical HELIOGRID measurements.

No provider response was fetched from a live API, no terms were copied into runtime code, and no rights clearance is asserted. The later pinned-code review retrieved repository text from GitHub only; it did not execute historical code or fetch provider data.

## AI technical review (2026-10-29)

Reviewer role: AI technical evidence reviewer. This review checked the claims above against the linked official material on 2026-10-29. It is not a human legal/privacy review, project-specific rights approval, or provider authorization.

Its licence page requires an Open-Meteo link beside displayed location data and lists upstream datasets under different licences. The table above now captures both points.
