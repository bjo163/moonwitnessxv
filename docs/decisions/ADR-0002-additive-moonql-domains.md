# ADR-0002 — Additive MoonQL Domain Architecture

- **Status**: ACCEPTED
- **Date**: 2026-10-26
- **Context**: MoonWitness XV Architecture & Domain Expansion (G1–G5)
- **Supersedes**: Historical XIV Knex/Objection migrations

---

## 1. Konteks & Latar Belakang

MoonWitness XV saat ini memiliki implementasi Fastify Hub dan ORM teruji (`@moonwitness/moonql`) yang menopang domain **D00 Identity & Ops** dan **D09 Signal/Radio**. Ketika kebutuhan program berkembang ke domain **D01 Corpus**, **D02 UNILEX**, **D05 Research**, dan **D07 Story**, sistem membutuhkan arsitektur yang:
1. **Aditif**: Menambahkan modul domain baru tanpa mengubah kode inti atau merusak fitur radio yang sedang berjalan.
2. **Satu Otoritas Runtime**: Tidak membuat server Fastify atau proses database sekunder yang redundan.
3. **Ketat Hak Akses**: Setiap domain baru wajib menerapkan kebijakan *Deny-by-Default* untuk model sensitif.

---

## 2. Keputusan Arsitektur (*Decision*)

1. **Format Ekstensi Standar (`defineAddon`)**:
   - Setiap domain baru diimplementasikan sebagai paket mandiri di bawah `packages/moonql-<domain>` (atau `packages/<domain>`) menggunakan fungsi `defineAddon` dari `@moonwitness/moonql`.
   - Addon mendaftarkan model tabelnya secara deklaratif (`defineModel`), relasi (`m2o`, `o2m`), hook lifecycle, dan tugas terjadwal (`crons`).

2. **Wiring Terpusat di `apps/radio/src/addons.ts` (Target ARSY)**:
   - Hub hanya memiliki satu berkas konfigurasi pendaftaran addon:
     ```typescript
     export const addons: AnyAddon[] = [
       base, auth, stations, schedule, playlog, apikeys, settings, ops,
       // domain baru ditambahkan secara aditif di sini:
       // corpus, unilex, ontology, research, story
     ]
     ```
   - Urutan array tidak berpengaruh karena MoonQL melakukan *topological sort* berdasarkan dependensi (`depends: ['auth', ...]`).

3. **Auto-REST & Collision Protection**:
   - Rute REST dibuat otomatis di bawah `/api/v1/<model_name>`.
   - Modul rute handwritten (seperti `health`, `metrics`, `studio`, `channels`, `denpa`) dilindungi oleh opsi `reservedPaths` saat bootstrap sehingga autogenerated model tidak akan pernah menimpa rute manual.

4. **Kompabilitas Mundur (*Backward Compatibility Guarantee*)**:
   - Rute lama (`/api/v1/stations`, `/api/v1/schedules/on-air`, `/api/v1/health`) tetap mempertahankan path, tipe data, dan format envelope yang ada.
   - Peningkatan versi skema dipantau ketat oleh `pnpm gen:sdk:check` (SDK drift gate).

---

## 3. Konsekuensi (*Consequences*)

### Positif:
- **Zero Regression**: Domain radio live streaming tidak terganggu saat fitur baru dimasukkan.
- **Kompilasi Cepat & Type-Safe**: Tipe TypeScript diturunkan otomatis ke SDK `@moonwitness/moonql-client` tanpa menulis ulang interface REST.
- **Dua Engine Didukung Penuh**: Semua model baru otomatis berjalan baik di PostgreSQL (produksi) maupun In-Memory engine (pengujian unit cepat).

### Hal yang Perlu Diperhatikan:
- Setiap penambahan model baru harus memiliki deklarasi `acl` eksplisit agar tidak terbuka secara publik secara tidak sengaja.
