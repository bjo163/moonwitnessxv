# MoonUI component behavior bible — DRAFT
[Master Design](../../MASTER_DESIGN.md). Buttons/links use native semantics, visible focus, pending/disabled states and no duplicate submits. Text inputs/selects associate labels, help and errors. Tabs/menus must implement keyboard arrow/Home/End, Escape for transient menus and focus restoration, ARIA selected/current distinctions. Tables represent true headers, empty/error/online states and filter data only with backend authorization. Reader preserves original edition, script/RTL, diacritics, rights and citation; UI translations must not overwrite sources. Radio playback must follow deliberate user gesture. Test id/en expansion, keyboard-only, screen-reader labels, mobile, reduced motion, dynamic/error and privacy denial. These are target contracts, not claims already implemented.
