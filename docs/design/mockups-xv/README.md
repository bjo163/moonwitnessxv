## Important distinction
- **SVGs in this folder are documented visual layouts**, not app routes or real-time dashboards.
- **The earlier high-resolution PNG/HTML package is a separate chat artifact**; do not assume these SVGs contain all pixel-level reference information.
- No original third-party stock photos, screenshot character portraits, music, unlicensed fonts or live service credentials were added.
- Treat first-party ink illustration licensing and SVG author/source as reviewable project material before general public reuse.
- Clone/reuse **only** existing MoonUI components and the authorized runtime; do not copy the SVG's demo status labels into a real operator screen.
