# M40 — ORBIT: Spatial Agent Operations Frontend

**Group:** G7 — ECOSYSTEM · **Priority:** P1 · **Status:** PLANNED · **This documentation change does not create app code or close implementation tasks.**

## Outcome

Deliver `apps/orbit` as a standalone Next.js frontend within XV for a smooth futuristic 3D view of agent/workstation/task operations, plus a fully usable accessible 2D fallback. It must have an independent frontend build/deploy boundary while using existing D00/ARSY authority.

**Canonical architecture:** [ADR-0004](../decisions/ADR-0004-empire-surfaces.md) · [ORBIT contract](../architecture/ORBIT.md) · [Master Design](../../MASTER_DESIGN.md).

## Non-goals and ownership

- No second backend, database, SQL owner, identity provider, login system, model router, agent executor, publishing engine, or graph store.
- No new domain assignment. ORBIT is a frontend, not a service.
- No fake agent status, simulated actions shown as live, browser-exposed service credentials, auto-approval/publication, or replacement for Headquarters/Cockpit.
- No immediate extraction into a separate GitHub repository.

## Dependency order

M40-01 first. M40-03 (scene prototype) and M40-05 (read-model contract) can proceed in parallel after workspace setup. M40-06 is blocked until relevant M28-13/M28-14 and M29-05 evidence is verified. M40-08 depends on M20/M37. M40-10 is the release evidence gate.

### M40-01 — Scaffold standalone ORBIT workspace and build boundary

**Depends on:** M01-02, M19-01

**Scope:** Create `apps/orbit` and `@moonwitness/orbit` using current Next.js/React conventions. Register workspace/build/typecheck/lint/design/CI/deploy gates. Pick port/topology only after review.

**Definition of done:** Frozen install, package/root checks pass, app shell works with ARSY offline, no new backend/data owner, no existing app regression.

### M40-02 — MoonUI shell, navigation, and id/en locale parity

**Depends on:** M40-01, M05-09, M05-10, M30-02, M30-03

**Scope:** Build an independent shell linked from 100CENTER but not nested in HQ routes. Use certified MoonUI and accepted locale contracts; keep auth/data outside the WebGL client boundary.

**Definition of done:** Locale parity/missing-key, keyboard/focus/labels/error/reduced-motion checks pass; no arbitrary hex or private HQ imports; works without WebGL.

### M40-03 — Spatial scene with clearly labelled simulated fixtures

**Depends on:** M40-01, M40-02

**Scope:** Audit Three.js/React Three Fiber/Drei compatibility and licensing, then lazy-load a bounded workstation/agent/task scene with stable selection. Mark every fixture SIMULATED.

**Definition of done:** Client-only loading, deterministic selection, accessible 2D inspector, visibly simulated fixtures, performance/provenance evidence, no unlicensed art.

### M40-04 — 2D accessibility fallback and 3D performance gates

**Depends on:** M40-03, M30-04, M30-05

**Scope:** Provide equivalent 2D task/workstation list and inspector. Respect reduced motion and test keyboard, screen-reader names, focus, contrast, narrow layouts, and WebGL failure.

**Definition of done:** Core actions work without WebGL/hover/color/sound; reduced motion halts nonessential animation; measured performance evidence recorded.

### M40-05 — Typed read-only agent/task/event projection contract
