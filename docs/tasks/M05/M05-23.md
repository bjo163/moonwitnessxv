# M05-23 — Localize shared developer/operator CLI human output

**Execution:** LEAF, P1/D2; owner platform/cli; status OPEN. **Dependencies:** M05-08, M05-10. Canonical task status: [TODO](../../../TODO.md); milestone context: [M05](../../milestones/M05.md).

## Scope

Localize human-readable output from repository-wide CLI utilities that are not owned by one application: the `moon` operator command (`packages/cli/src`) and the MoonQL SDK generator/check command (`apps/radio/src/tools/gen-sdk.ts`). Cockpit launcher output remains owned by M19-25/M19-30; Sentinel worker/CLI output remains owned by M05-16; ARSY API errors/diagnostics remain owned by M05-14. M05-09 decides whether the embedded ARSY launchpad/Studio UI is part of locale scope. Do not duplicate those owners.

## Deliverable and acceptance

- Use the shared id/en catalog and locale contract established by M05-09/M05-10; do not add a private dictionary or a new locale resolver.
- Localize user-facing help, status, and actionable errors. Keep command names, flags, file paths, IDs, exit codes, output formats consumed by scripts, and machine-readable behavior stable.
- Add focused positive and negative output tests for both locales and contract invariants. Record exact commands, outputs, and SHA.
- No CLI/UI implementation task is authorized until its prerequisites are met. The task is not complete based on source edits or CI configuration alone.

## Boundaries

Do not translate generated SDK/API identifiers, provider IDs, code-generation data, or raw errors passed through from the runtime. No interactive TUI was found in these utilities. Rollback is removal/reversion of the CLI catalog adapter and its tests; generated API artifacts must remain byte-for-byte unchanged except for separately authorized schema changes.
