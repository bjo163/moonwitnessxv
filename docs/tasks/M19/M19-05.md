# M19-05 — Test Arabic/Hebrew/Greek scripts, RTL and diacritics

Status: implementation and focused evidence in progress. Canonical status is [TODO.md](../../../TODO.md); this packet records acceptance for the Dock reader slice.

## Owner and boundary

- **Owner:** Dock reader surface.
- **Scope:** verify the existing `ReaderView` React output with synthetic-only Arabic, Hebrew and Greek strings. Preserve language tags, recorded text direction, combining marks, and the `auto` fallback when direction is unknown.
- **Out of scope:** changing reader semantics, inferring a language direction, modifying CSS/layout globally, loading Hub or corpus data, using real scripture/translation/witness material, or making rights decisions.
- The test contract is based on `TODO.md` and [M19 milestone context](../../milestones/M19.md). The prior static test at [M19-05 audit](../../audit/M19-05-script-rtl-diacritics-5b70e76.md) remains complementary; it pins source-level refusals and synthetic transport round-trips.

## Definition of done

1. A registered automated test renders the production `ReaderView` with synthetic code-point-built fixtures only.
2. Rendered Arabic carries `lang="ar"` and `dir="rtl"`; Hebrew carries its declared `rtl`; Greek carries its declared `ltr`.
3. The rendered text keeps its combining marks and exact synthetic string; no real or private source text enters fixtures or reports.
4. A row with missing direction renders `dir="auto"`, and a negative assertion rejects a guessed `ltr` value for that row.
5. The rendered fixture contains no bidi control characters or HTML entity encoding.
6. Focused test, scoped lint, and diff checks pass on the exact implementation SHA. The TODO checkbox remains open until the task owner reviews exact-SHA evidence and all acceptance clauses are met.

## Evidence and limits

The automated test exercises React server rendering and markup. It does not claim a visual browser screenshot, glyph/font coverage across operating systems, live Hub integration, or human accessibility certification. Browser screenshots and broader experience-mode behavior remain in M19-06/M19-07 scope.

Rollback is limited to the M19-05 test, root test registration, and this packet; no runtime reader behavior or data is changed.
