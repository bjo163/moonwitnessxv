# M19-36 — Centralize MoonUI components and enforce shared-first consumption

**EXECUTABLE LEAF, NOT VERIFIED** · Priority P1 · Difficulty D3. One milestone owner, one task ID and one changed-file claim. [Canonical task state](../../../TODO.md) · [Milestone](../../milestones/M19.md).

## Task objective and minimal grounded context
Make `@moonwitness/moonui` the only owner of UI components and prove it with a gate that fails when a consumer writes its own. Authority: [ADR-0017](../../decisions/ADR-0017-shared-first-component-ownership.md) (ACCEPTED, supersedes ADR-0009 §2.4). Primary paths: `scripts/check-ui-consistency.mjs`, `packages/eslint-config/src/{index,plugin}.js`, `docs/design/moonui-exceptions.json`, `packages/moonui/src/**`, and the five forked components named in the ADR context.

## Boundaries and work plan
1. Pin the branch (`dev`), baseline SHA and working-tree state before editing; preserve unrelated dirty files.
2. Rewrite `scripts/check-ui-consistency.mjs` into six checks (surface adoption with auto-discovery, token purity, component-class denylist by suffix, typography, duplicate-component matrix, exception-ledger ratchet) with `--root`, `--json` and `--update-ledger`.
3. Generate `docs/design/moonui-exceptions.json` from the measured tree; the ledger may only shrink afterwards, and `RATCHET` lives in the script source.
4. Add `@moonwitness/shared-ui-only` to `packages/eslint-config/src/plugin.js`, enable the dormant `enforce-token-purity`, and add `apps/empire-web` to the TSX and restricted-import blocks.
5. Migrate the known forks onto existing primitives: Cockpit modals → `Modal`/`AlertDialog`/`KbdLegend`, ECHOLOG confirm → `AlertDialog`, Orbit nav → `SectionNav`, Orbit `Chip` → `Pill`, Empire `StatRow` and Dock `.dk-paper-stat-row` → `StatStrip`.
6. Promote Dock's `PanelState`/`OutcomePanel` and `SpaceCard`/`SpaceGrid` into MoonUI, keeping copy and data app-side.
7. Positive test: `pnpm ui:check`, `pnpm lint`, `pnpm --filter @moonwitness/moonui test` and the cockpit/echolog/orbit/dock suites pass on the changed tree.
8. Negative test: `test/governance/ui-consistency-linter.test.mjs` proves the gate fails on a local `Chip`, a `.x-btn` stylesheet rule, an icons-only import, a component duplicated across two apps, and a ledger over its ceiling.
9. Stop BLOCKED if ADR-0017 is rejected, if a migration would break a landmark or geometry invariant without an owner decision, or if the exact-SHA CI gate is unavailable.
