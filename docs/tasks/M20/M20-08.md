## Boundaries and work plan
1. Fix the logical grant record, append-only events, state machine, validation invariants and the server-side D08 loader contract. Do not choose a storage engine, DDL, route shape or UI.
2. Cover every ADR-0015 decision: D00-bound grants, unchanged login roles, two-admin issuance for `approve`, single-admin `author`, mandatory expiry, immediate revocation, no break-glass/delegation/machine review, lane mapping, fail-closed rechecks, legacy values and retention deferral.
3. Positive check: every ADR-0015 decision maps to a named invariant, transition or loader rule.
4. Negative check: the artifact specifies refusal behaviour for self-grant, same-admin confirmation, unknown lane, missing/expired/revoked grant, caller-supplied grants, legacy reviewer values and store failure.
5. State explicitly that the residual two-account linkage risk is accepted and not solved, and that no grant or principal is assigned.
6. Do not create schema, migration, route, UI, package code or tests. Do not edit TODO status in the leaf; the integrator closes the row after review.
7. Inspect the full diff for unrelated edits, secrets, identity/API drift or content leakage.
