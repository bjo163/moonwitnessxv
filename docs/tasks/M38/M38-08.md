# M38-08 — Implement the D18 store, migrations and single-owner guard

**EXECUTABLE LEAF, NOT VERIFIED** · Priority P0 · Difficulty D4. [Canonical task state](../../../TODO.md) · [Milestone](../../milestones/M38.md).

## Objective and grounded context
D18 needs durable message state, but `packages/moonql/drizzle.config.ts` declares itself the only migration home and MoonQL has no `pgSchema` support. ADR-0006 accepts exactly one second SQL owner scoped to a `skylink` schema; this task builds it and closes the loophole with a guard test.

## Boundaries
- Paths: `packages/skylink-store/{package.json,tsconfig.json,drizzle.config.ts,src/*}`, guard test in `apps/radio/test/workspace-topology.test.ts`.
- `apps/**` must not import `drizzle-orm`/`postgres`; all SQL lives in the package.
- `schemaFilter: ['skylink']` so `push`/`introspect` never consider MoonQL tables.
- No credentials in the database: `channel_accounts.auth_ref` is a reference only.

## Work plan
1. Pin the SHA; read `packages/moonql/drizzle.config.ts` and the topology test.
2. Declare `pgSchema('skylink')` tables: `channel_accounts`, `conversations`, `messages`, `delivery_attempts`.
3. Provide a migration runner and a `drizzle.config.ts` with `schemaFilter`.
4. Add the guard test enumerating every member that imports `drizzle-orm`/`postgres` and asserting the set is exactly `{packages/moonql, packages/skylink-store}`.
5. Add repository helpers with bounded queries and no raw string interpolation.
6. Positive evidence: migrate up on the local Postgres, insert/read a message, migrate down cleanly. Negative evidence: a third package importing drizzle must fail the guard test.
7. Confirm `pnpm db:push` (MoonQL) does not attempt to touch `skylink.*` — show the output.
8. Stop BLOCKED if no local Postgres is available; do not substitute SQLite or in-memory as "proof".

## Rollback
Drop schema `skylink` and revert the package; MoonQL data is untouched.
