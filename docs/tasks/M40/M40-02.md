## Objective

Build the standalone MoonUI shell and navigation for ORBIT, ensuring complete `id`/`en` locale parity, accessible keyboard navigation, reduced-motion compliance, and strict token purity without nesting in Headquarters internal routes or importing private HQ modules.

## Boundaries

1. **Independent Shell:** Hosted at `apps/orbit` (`http://localhost:3007`); linked from 100CENTER/Headquarters via standard cross-app URL/link, never nested in HQ routes.
2. **Certified MoonUI Primitives:** Consume `@moonwitness/moonui` components (`Badge`, `Card`, `LiveDot`, `Button`, `LinkButton`, `Breadcrumbs`, etc.). Zero rogue hex colors; all colors flow from Moon design tokens (`var(--cyan)`, `var(--pink)`, `var(--ink)`, `var(--surface)`, `var(--border)`, `var(--fg)`, `var(--muted)`).
3. **Locale Parity Contract:** Shared `defineLocaleCatalog` from `@moonwitness/core` with identical key sets for English (`en`) and Indonesian (`id`). Zero untranslated raw key fallbacks.
4. **Accessibility & Reduced Motion:**
   - Accessible keyboard focus states (`:focus-visible` with high contrast outline).
   - Skip to main content link (`#main-content`).
   - Standard ARIA landmarks (`banner`, `navigation`, `main`, `contentinfo`, `status`).
   - `@media (prefers-reduced-motion: reduce)` halts non-essential animations.
5. **Works Without WebGL:** Shell and 2D operations inspector function completely without WebGL, GPU acceleration, hover, or sound.
6. **Zero Private HQ Imports:** Never import from `apps/headquarters/src` or internal HQ routes.

## Acceptance Evidence

- Positive: Locale parity test proves identical keys in `en` and `id`; shell renders localized chrome in both languages; skip-to-content and ARIA landmarks verified; reduced-motion CSS rule halts animation.
- Negative: Rejects mismatched locale keys; rejects private HQ imports; rejects arbitrary hex colors.
- Suite: Unit tests, typecheck, lint, UI consistency check, and Next.js production build pass cleanly.
