# M40-03 — Spatial scene with clearly labelled simulated fixtures

**COMPLETED, VERIFIED** · Priority P1 · Difficulty D3. [TODO](../../../TODO.md) owns status. [Milestone](../../milestones/M40.md) · [Architecture](../../architecture/ORBIT.md) · [Audit](../../audit/M40-03-spatial-scene-fixtures.md).

## Objective

Deliver the 3D-first spatial operations viewport in `@moonwitness/orbit` using React Three Fiber, Three.js, and Drei. The scene must be client-only lazy-loaded, bounded, deterministic in selection, clearly label every node as `SIMULATED`, synchronize with an accessible 2D detail inspector, and consume 100% procedural geometric assets adhering to MoonUI design tokens without any unlicensed external 3D files.

## Boundaries

1. **Client-Only Boundary:** The 3D scene must load dynamically with `ssr: false` to ensure WebGL context only mounts client-side, avoiding SSR hydration/Turbopack failures.
2. **Deterministic Selection:** Selecting a node in 3D updates the 2D inspector drawer, and selecting a row in the 2D list focuses and highlights the corresponding 3D mesh.
3. **Visibly Simulated Fixtures:** Every 3D mesh (workstation, agent, queue origin) carries a persistent, readable `SIMULATED` holographic badge.
4. **Procedural Geometry & MoonUI Palette:** Use 100% procedural Three.js primitives (hex prisms, octahedrons, spline lines, torus rings, grid planes) colored via MoonUI tokens (`--cyan`, `--pink`, `--ok`, `--accent`, `--surface`, `--ink`). Zero `.gltf`, `.glb`, or external model files.
5. **Reduced Motion & Performance:**
   - Honor `prefers-reduced-motion` by disabling or clamping rotation/orbit speeds.
   - Bounded camera controls (clamped polar angles, restricted zoom distance).
   - Clean WebGL unmounting and disposal without memory leaks.
6. **Accessible 2D Inspector:** The full operational state (cycle, steps, lease token, associated tasks, HQ approval handoffs) remains 100% legible and operable even if WebGL is unavailable.

## Acceptance Evidence

- Positive: `OrbitSpatialViewport` lazy-loads client-side; clicking a 3D node opens the 2D inspector; every node renders `SIMULATED`; `prefers-reduced-motion` halts rotation; package build and tests pass.
- Negative: Rejects external binary 3D assets (`.gltf`, `.glb`, `.obj`); fails if any simulated fixture lacks `SIMULATED` metadata; zero rogue hex colors.
- Suite: Unit tests, typecheck, Next.js build, UI consistency check, and ESLint pass cleanly.
