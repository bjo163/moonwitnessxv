## Objective

Deliver the 2D accessibility fallback and 3D performance gates for `@moonwitness/orbit`. Ensure core operations remain 100% accessible and operable when WebGL is unavailable or disabled, respect `prefers-reduced-motion`, provide keyboard-accessible view mode switching, enforce non-reliance on color/hover/sound alone, adapt to narrow mobile viewports, and verify clean GPU memory disposal without leaks.

## Boundaries

1. **Deterministic WebGL Fallback:** When WebGL context creation fails, hardware acceleration is disabled, or the user selects 2D mode, the application must gracefully display an accessible 2D operations view with zero crashes.
2. **No Reliance on Color/Hover/Sound:** Every operational status (`STANDALONE`, `WAITING_APPROVAL`, `EXECUTING`, `IDLE`) must have explicit textual labels.
3. **Full Keyboard & Screen-Reader Operability:** All core actions (selecting nodes, opening/closing inspector, reviewing approval payloads, switching view modes) must be accessible via standard keyboard navigation (`Tab`, `Enter`, `Space`, `Escape`) with visible focus rings (`:focus-visible`).
4. **Mobile & Narrow Viewport Adaptation:** The UI must reflow seamlessly down to 390px without horizontal scrollbars, and the inspector drawer must adapt to an inline or full-width sheet on screens $\le 768\text{px}$.
5. **Performance & Memory Gates:** WebGL textures, geometries, materials, and animation frames must be disposed deterministically on unmount to prevent memory leaks.

## Acceptance Evidence

- Positive: WebGL capability detector reliably falls back to 2D view; view switcher toggles between 3D Spatial and 2D Accessible mode; keyboard navigation works across all elements; reduced motion halts animation; narrow viewport CSS rules adapt layout; 100% MoonUI tokens.
- Negative: Zero reliance on color alone; zero unhandled WebGL exceptions; zero binary 3D model files.
- Suite: Unit tests, typecheck, Next.js build, UI consistency check, and monorepo ESLint pass cleanly.
