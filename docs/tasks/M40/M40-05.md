## Objective

Deliver the typed read-only projection contract for `@moonwitness/orbit`. Create a pure, robust projection engine that parses and normalizes operational data from ARSY runtime feeds, LUMEN event streams, and deterministic simulated fixtures into strongly-typed view models. Guarantee truthful representation of data source, freshness, and errors; fail-safe unknown or malformed data to `UNKNOWN`; and guarantee zero service credentials in client bundles.

## Boundaries

1. **Pure Read-Only Projection:** No database tables, SQL drivers, or backend mutations. The projection normalizer is a deterministic pure function.
2. **Fail-Safe to UNKNOWN:** Malformed, missing, or unrecognized states (e.g. invalid agent state, corrupt zone, garbage payload) must map safely to `UNKNOWN` without throwing exceptions or crashing the UI.
3. **Truthful Freshness & Provenance:**
   - Fixtures explicitly declare `sourceType: 'SIMULATED'`.
   - Live feeds declare `sourceType: 'LIVE'`.
   - Timestamps older than the stale threshold (60s) or with extreme clock drift mark `freshness: 'STALE'`.
   - Missing or invalid timestamps mark `freshness: 'UNKNOWN'`.
4. **Honest Error & Outage Mapping:**
   - HTTP 401/403 or `{ error: 'UNAUTHORIZED' }` maps to `connectionStatus: 'UNAUTHORIZED'`.
   - HTTP 503 or backend unreachable maps to `connectionStatus: 'OFFLINE'` with an explanatory audit trace.
5. **Credential Isolation:**
   - Any sensitive keys matching `/(key|secret|token|password|auth)/i` in arbitrary raw payloads are sanitized before projection to the client boundary.
6. **Preserve Human Approval Requirements:**
   - Actions requiring human approval preserve their `approvalPayload` and handoff destination (`100CENTER` HQ) without auto-bypassing governance.

## Acceptance Evidence

- Positive: Valid fixtures and live feeds parse with 100% structural integrity; fresh timestamps evaluate to `FRESH`.
- Negative:
  - Corrupt or malformed input maps safely to valid state with `UNKNOWN` values without throwing.
  - Stale timestamps (> 60s) evaluate to `STALE`.
  - Unauthorized responses map to `UNAUTHORIZED`.
  - Service unavailable responses map to `OFFLINE`.
  - Sensitive tokens are stripped/redacted from projected objects.
- Suite: Unit tests, typecheck, Next.js build, UI consistency check, and ESLint pass cleanly.
