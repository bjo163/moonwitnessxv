# M40-06 — Bind the UI to verified ARSY runtime state

**EXECUTABLE LEAF** · Priority P1 · Difficulty D4. [TODO](../../../TODO.md) owns status. [Milestone](../../milestones/M40.md) · [Architecture](../../architecture/ORBIT.md) · [Projections](../../tasks/M40/M40-05.md).

## Objective

Bind `@moonwitness/orbit` to verified ARSY runtime state, enforcing that `LIVE` status is rendered **only** when backed by a verified, healthy ARSY runtime feed with verified timestamp freshness. Outage, timeout, network error, and unauthenticated/unauthorized states must render honest, un-faked operational badges (`OFFLINE`, `UNAUTHORIZED`, `UNKNOWN`). Animation and 3D scenes must never masquerade as runtime execution when data is stale or the backend is disconnected.

## Boundaries and Integrity Requirements

1. **Frontend-Only Boundary:** `@moonwitness/orbit` remains a Next.js frontend with zero database tables, SQL drivers, or backend mutations.
2. **Single Hub Authority:** ARSY (`apps/arsy`) at port 3000 is the sole physical Fastify/MoonQL Hub. ORBIT consumes the shared `apiBaseUrl(process.env)` resolver.
3. **Truthful State & Freshness:**
   - `LIVE`: Rendered ONLY when connected to an authorized ARSY runtime source and freshness is strictly `FRESH`.
   - `STALE`: Rendered if `now - lastSyncTimestamp > staleThresholdMs` (default 60s).
   - `OFFLINE`: Rendered if ARSY is unreachable, timed out, or connection refused.
   - `UNAUTHORIZED`: Rendered on 401/403 responses.
   - `SIMULATED`: Rendered when explicitly in local simulated mode (`ORBIT_SIMULATED=true` or offline fallback).
4. **Credential Isolation:** No service tokens, database passwords, or auth keys in browser bundles or client-facing responses.
5. **Radio/SIGNAL Invariance:** Zero regressions in existing ARSY Radio/SIGNAL routes or playback.

## Acceptance Evidence

- Positive live state binding:
  - When ARSY Hub is healthy and reachable, runtime state is queried and projected into `OrbitStateProjection`.
  - Fresh timestamps produce `freshness: 'FRESH'` and render the active `LIVE` indicator.
- Negative tests:
  - Unreachable ARSY Hub (timeout / ECONNREFUSED) fails safely to `connectionStatus: 'OFFLINE'`, surfaces honest outage indicator, and offers offline simulation fallback without crashing.
  - Expired or stale timestamps (> 60s) produce `freshness: 'STALE'`, displaying caution warning with exact last known timestamp.
  - HTTP 401/403 produces `connectionStatus: 'UNAUTHORIZED'`.
  - Corrupted, missing, or malformed payloads normalize gracefully with `UNKNOWN` defaults.
- Zero secrets committed or leaked in client responses.
- Full verification: `orbit test`, `orbit typecheck`, `pnpm build:web`, `pnpm ui:check`.
