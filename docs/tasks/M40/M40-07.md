# M40-07 — Task queue, workstation and agent inspectors

**EXECUTABLE LEAF** · Priority P1 · Difficulty D3. [TODO](../../../TODO.md) owns status. [Milestone](../../milestones/M40.md) · [Architecture](../../architecture/ORBIT.md) · [Projections](./M40-05.md) · [Runtime binding](./M40-06.md).

## Objective

Deliver filterable task queues and workstation/agent detail-and-activity panels for `@moonwitness/orbit`, built **only** from the typed read-only projection contract (M40-05) bound to verified runtime state (M40-06). The 3D scene and the 2D lists must resolve the same records through one shared selection control, preserve canonical event order, and expose source and freshness where the projection carries them.

## Boundaries and Integrity Requirements

1. **Derived, never invented.** Every queue row, count, and activity entry is a subset of `OrbitStateProjection`. The filter layer adds no records, re-orders nothing, and never synthesizes progress, tool calls, or status text.
2. **Fail-closed restricted view.** When the projection is `UNAUTHORIZED`, no rows are displayable: the workspace renders an explicit restricted notice with `role="alert"` and disables the filter bar instead of showing stale or partial rows.
3. **Honest empty and failed states.** A filter that matches nothing renders `queueEmptyState`; a node with no bound trace renders `queueNoActivity`; `OFFLINE`/`UNKNOWN`/errored projections render the diagnosis-only `queueFailedState`. None of these fall back to invented data.
4. **Single shared selection.** One handler drives both the spatial viewport and the 2D lists; ids are unique across workstations and agents so a selection always resolves to exactly one record.
5. **Frontend-only boundary.** No SQL driver, database table, identity owner, approval engine, or private Headquarters import is introduced.
6. **Locale parity.** Every new copy key exists in both `en` and `id` with non-empty, genuinely distinct translations.

## Acceptance Evidence

- **Positive:** filters by status, priority, assigned agent, zone, agent state, and free-text search each return a deterministic subset; counts equal the real projection counts; the selected agent resolves its canonical bound task and only its real traces, in original order.
- **Negative:** corrupt entities (invalid `state`, `status`, `zone`) map to `UNKNOWN` and stay filterable; a non-array `recentTraces` counts as zero records; an unauthorized projection yields zeroed queues; unknown ids resolve to `undefined`/`null` with no fabricated detail panel; empty inputs never throw.
- **Accessibility & keyboard:** the filter bar is a `role="search"` region with a `type="search"` input, `aria-expanded` disclosure, `aria-controls`, labelled `role="group"` chip sets, and `aria-pressed` chips; filtered list items keep `tabIndex`, `role="button"`, Enter/Space activation and Esc dismissal; state notices are announced (`role="status"` / `role="alert"`).
- **Design integrity:** filter/panel styles use MoonUI CSS variables only — the suite asserts zero hex literals in `globals.css`; reduced-motion contract is preserved; no audio or hover-only dependency in the new components.
- **Full verification:** `pnpm --filter @moonwitness/orbit test`, `pnpm --filter @moonwitness/orbit typecheck`, `pnpm exec eslint apps/orbit`, `pnpm ui:check`, `pnpm build:web`, plus ARSY Radio/SIGNAL regression.
