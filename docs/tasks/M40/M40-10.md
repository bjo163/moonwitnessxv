# M40-10 — Exact-SHA release acceptance, rollback, and extraction review

**Milestone:** [M40 · ORBIT — Spatial Agent Operations](../../milestones/M40.md)
**Status:** closed
**Owner:** `apps/orbit`
**Depends on:** M40-01..09

## 1. Objective

M40-01..09 each carry their own scoped tests. M40-10 is the gate that says something
narrower and harder: at one recorded SHA, the built ORBIT artifact was run, the flows the
milestone claims were observed rather than inferred, a rollback was rehearsed rather than
asserted, and every claim in the closure text is tied to output that exists in this
repository.

## 2. Scope

1. **Runtime acceptance** — `apps/orbit/test/orbit-runtime-smoke.test.mjs` (opt-in,
   `ORBIT_RUNTIME_SMOKE=1`, like the existing `ORBIT_SCAN_BUNDLE=1` scan). It starts a real
   `next start` production server against throw-away `node:http` hub stand-ins and asserts
   on the HTTP responses a browser receives: 401 → `UNAUTHORIZED` with zero rows and
   `UNKNOWN` freshness; a healthy hub → `LIVE_CONNECTED`/`FRESH` with the hub named in
   `dataSource`; an 11-minute-old timestamp → `STALE` and not `FRESH`; a refused socket →
   `OFFLINE` behind `role="alert"`; conflicting `ARSY_API_URL`/`RADIO_API_URL` → `OFFLINE`
   with no origin claimed; a `302` to a decoy → `OFFLINE` with the decoy's request count at
   `0`. Each scenario starts and stops its own server, and both locale `?locale=id` and an
   unsupported `?locale=fr` are read from the delivered HTML.
2. **Browser walkthrough** — the approval, keyboard and 3D/2D flows were driven in a real
   browser against that server: Enter selects a task row, the handoff renders as a link to
   the validated 100CENTER origin with URL-encoded identifiers, Escape dismisses the
   inspector, the WebGL canvas and the 2D grid are in the same document, and the 2D toggle
   removes the canvas. Recorded verbatim in
   [docs/audit/M40-10-release-acceptance.md](../../audit/M40-10-release-acceptance.md) §4.
3. **Rollback rehearsal** — every ORBIT milestone commit was reverted, in order, in a
   throw-away worktree at the recorded SHA, and the resulting path set was checked against
   the other apps. §5.
4. **Extraction review** — each claim in the M40 rows and in `apps/orbit/README.md` was
   re-read against the output that is supposed to support it, and the claims that are *not*
   supported were written down as not-claimed rather than softened. §6.
5. **Defect found and fixed by this gate** — `?locale=id` rendered Indonesian copy while the
   document element still said `lang="en"`. The root layout cannot see `searchParams`, so the
   URL locale never reached it. Fixed with the edge entry point ORBIT was missing
   (`src/middleware.ts`, `src/lib/orbit-locale-header.ts`) and two tests. §3.

## 3. Boundaries held

- Acceptance touches no other app: the M40-10 delta is `apps/orbit/**` and `docs/**` only.
- The rehearsal worktree was created and removed by this task; no shared branch, remote,
  container or deployment was touched.
- The runtime gate binds an ephemeral port and terminates its own server in `finally`, so a
  passing run leaves no listener behind.
- The gate is opt-in, consistent with the repository's thin-CI policy: the default `pnpm
  --filter @moonwitness/orbit test` run does not need a build artifact or a port.

## 4. Acceptance evidence

Recorded in [docs/audit/M40-10-release-acceptance.md](../../audit/M40-10-release-acceptance.md):
frozen install at the recorded SHA, 88/88 orbit tests (including the built-bundle credential
scan and the new runtime smoke), 16/16 boundary tests, `@moonwitness/orbit` typecheck,
`eslint apps/orbit --max-warnings 0`, standalone build (3 routes plus the middleware entry),
`pnpm ui:check` 132 files / 0 violations, LUMEN 29/29 library plus 2/2 runtime tests, and the
browser DOM output for the approval, keyboard, locale and 2D-fallback flows.

## 5. Not in this task

  remain open. This gate accepts ORBIT's side only.
- No deployment. Nothing was published, containerised or pushed to infrastructure; the

- The live 100CENTER review queue was not contacted; the review link's destination was
  verified against the loopback default and the server-validated surface, not against a
  running headquarters.
