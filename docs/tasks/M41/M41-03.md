# M41-03 — Scaffold the reusable LUMEN framework package

**EXECUTABLE LEAF, NOT VERIFIED** · Priority P1 · Difficulty D3. [TODO](../../../TODO.md) owns status.

## Objective

Create the minimal private workspace package at **packages/lumen** named **@moonwitness/lumen**, following current XV package and TypeScript conventions. This is framework scaffolding, not the worker application.

## Boundaries

1. Depend on the accepted ADR and M41-02 public contracts.
2. Use the root pnpm workspace, root Node range and current TS project references/scripts.
3. Export stable public types and dependency-injected ports for a model gateway, tool registry/policy, run control, checkpoints, approvals, events, clock and budgets.
4. Keep importing the package free of network, database, environment-secret, timer-loop or server side effects.
5. Keep one package at first. Do not create lumen-core/types/worker helper packages without evidence of a second consumer.
6. Add no provider SDK, database library, queue or telemetry exporter merely for scaffolding.

## Acceptance evidence

- Positive: package builds, typechecks, exports its documented public entry and runs isolated tests.
- Negative: package can be imported without starting a worker or contacting ARSY/AI Gateway; invalid contract fixtures fail.
- Root workspace checks and a package focused test pass; unrelated manifests remain unchanged.
