# M41-04 — Implement the bounded single-agent execution loop

**EXECUTABLE LEAF, NOT VERIFIED** · Priority P1 · Difficulty D4. [TODO](../../../TODO.md) owns status.

## Objective

Implement LUMEN's own core loop for one agent per run: prepare authorized context, request a model response through an injected gateway port, validate proposed tool calls, execute permitted tools, record normalized outcomes and terminate safely.

## Boundaries

1. Depend on M41-03.
2. Use fake gateway/tool adapters for deterministic unit tests; live ARSY integration is not part of this task.
3. Enforce maximum loop iterations, deadline, cancellation and per-run resource budget.
4. Treat model output and tool responses as untrusted data; reject malformed calls and unknown tool IDs.
5. Persist/emit through injected ports only; the core does not own storage, HTTP, credentials or canonical run state.
6. Never treat a model response as permission or as verified source truth. Do not expose hidden chain-of-thought.
7. Keep the first loop sequential. No supervisor swarm, arbitrary code interpreter or automatic publishing.

## Acceptance evidence

- Positive: fake model returns a final answer; another fixture invokes one allowlisted tool and continues to completion.
- Negative: unknown tool, malformed arguments, max-iteration exhaustion, deadline, gateway error and cancellation stop with a typed outcome and no unauthorized side effect.
- Unit tests and typecheck pass; output is bounded and repeatable for identical fixtures.
