# M41-06 — Add the existing AI Gateway adapter

**EXECUTABLE LEAF, NOT VERIFIED** · Priority P1 · Difficulty D3. [TODO](../../../TODO.md) owns status.

## Objective

Implement the narrow adapter from LUMEN's model port to the actual current AI Gateway contract. Inspect live code and schemas before implementing; this packet does not prescribe unverified endpoints.

## Boundaries

1. Depend on M41-04 and use the current gateway implementation and auth contract.
2. Provider selection, credential storage, retries owned by the gateway and provider catalog remain outside LUMEN.
3. Map provider/gateway errors to typed outcomes without leaking secrets or raw sensitive payloads.
4. Enforce deadlines and cancellation where the gateway contract supports them; document any limitation.
5. Record token/cost usage only where actual gateway responses provide trustworthy values.
6. No direct provider SDK or credentials in the LUMEN package/runtime unless a separately accepted ADR changes this boundary.

## Acceptance evidence

- Positive: fake and actual contract tests cover a successful response, structured tool proposal and usage metadata when present.
- Negative: unauthorized, unavailable, malformed, timed-out and rate-limited gateway responses fail safely and do not trigger fallback to an unapproved provider.
- Verify contract drift and relevant typecheck/unit tests.

## Required report

Record inspected gateway paths/version, exact commands/results, changed paths, error mapping, unresolved contract limitations, reviewer and result SHA.
