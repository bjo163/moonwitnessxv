# M41-09 — Build the standalone internal worker application

**EXECUTABLE LEAF, NOT VERIFIED** · Priority P1 · Difficulty D4. [TODO](../../../TODO.md) owns status.

## Objective

Create **apps/lumen-runtime**, package **@moonwitness/lumen-runtime**, as a separately built and run worker application that imports the framework package. It is not a second Hub or a public API.

## Boundaries

1. Depend on verified package contracts and M41-06/M41-07 adapters; use fake adapters for isolated lifecycle tests before live ARSY integration gates open.
2. Follow current workspace, Node, TypeScript, lint, build, Docker/deployment and release conventions after inspecting the actual templates.
3. Support startup validation, readiness, graceful stop, cancellation propagation and bounded worker concurrency.
4. Do not expose task creation/approval/business endpoints. Any diagnostic health transport must be internal-only and its binding reviewed; do not reserve a public port.
5. No direct database connection, extra queue schema, Redis, public browser credentials or provider secrets.
6. Report worker liveness separately from upstream ARSY/Gateway availability. Never report LIVE run state from fixtures.

## Acceptance evidence

- Positive: runtime starts with fake adapters, claims a fixture, executes one permitted run, stops gracefully and exposes accurate internal readiness.
- Negative: missing config, denied authorization, unavailable ARSY, cancellation and shutdown reject or stop safely without executing unapproved tools.
- App build/typecheck/tests are separate from framework tests; root workspace gates are updated intentionally.

## Required report

Include startup/shutdown commands, package scripts, exact tests, changed paths, deployment/config boundary, reviewer and result SHA. No deployment is claimed by a local build.
