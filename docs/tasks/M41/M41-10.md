# M41-10 — Add tracing, metrics, redaction and execution budgets

**EXECUTABLE LEAF, NOT VERIFIED** · Priority P1 · Difficulty D3. [TODO](../../../TODO.md) owns status.

## Objective

Make agent execution inspectable through correlated traces and metrics, while enforcing runtime budgets and safe telemetry defaults.

## Boundaries

1. Depend on M41-04 and the actual gateway/runtime shape; use OpenTelemetry JavaScript compatible with the repo toolchain.
2. Correlate run, workflow version, step, gateway call, tool call, lease recovery and approval event using bounded identifiers.
3. Enforce maximum iterations, overall deadline, tool timeout, concurrency, and token/cost budgets only where the measurement source is trustworthy.
4. Exclude raw prompts, complete outputs, private witness content, arbitrary tool payloads, secrets and personal data from default logs/attributes.
5. Any optional payload capture needs explicit configuration, redaction, authorization and retention rules.
6. Do not publish fake usage metrics or invent health/state status. Do not make tracing a persistence substitute.

## Acceptance evidence

- Positive: fixture run creates correlated spans/metrics with accurate IDs, duration and errors.
- Negative: sensitive fixture values are absent from normal logs/spans; budget overflow stops the run safely and records a typed reason.
- Run tests with telemetry enabled and disabled.

## Required report

Record telemetry versions, fields/redaction policy, budget semantics, exact test commands/results, changed paths, reviewer and result SHA.
