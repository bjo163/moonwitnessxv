## Objective

Deploy the verified Story Universe static pilot to a new Vercel production project connected to `bjo163/moonwitnessxv`, using the promoted `main` source. The project owner explicitly authorized this isolated production release on 2026-10-29; ADR-0012 records its scope.

## Entry gates

- M42-01 is closed with exact-SHA test/build/browser evidence.
- The tested source has passed the required `dev` CI and been promoted to `main` by the existing guarded workflow.
- No unrelated working-tree changes are included in the source release.

- Root directory: `apps/empire-web`; framework: Next.js; static export output: `out`.

## Release verification

1. Record the new Vercel project ID, deployment ID, production URL, exact source revision and READY state.
2. Request `/id`, `/en`, and each localized `stories`, `stories/angelwithshotgun`, `characters`, and `ggs` route; confirm successful HTML and correct locale.

5. Check the unrelated Vercel project and its custom domain were not changed.
6. Record the previous deployment/rollback target and the exact revert or Vercel rollback procedure.

Use Vercel rollback/deployment controls only on the new `a-l-l-a-h-empire-web` project. If the project is misconfigured, disable or remove only that new project and revert the M42-02 settings commit; do not change Dock, the existing Empire project, domains or DNS.

Provide exact source SHA, project and deployment IDs, URL, live route/status/header and artwork evidence, previous rollback target, commands actually run, any limitations, and the final release state. A successful build or green CI alone does not close this task.
