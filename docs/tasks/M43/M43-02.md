# M43-02 — Type the skins and gate them with tests

**EXECUTABLE LEAF, VERIFIED 2026-10-29 at `1fa799d`.** · Priority P1 · Difficulty D3 · Owner: design system. [TODO](../../../TODO.md) owns status.

## Objective

Give the two skins a typed, tested contract so a later edit cannot silently fork the palette, rename a role, or move geometry into a skin block.

## Entry gates

- M43-01 is closed: `moon.css` carries both skin blocks.

## Scope

- `MOON_SKINS` in `packages/moonui/src/tokens.ts` exposes `zine` and `empire` with an identical key set.
- `MOON_COLORS` is unchanged and asserted equal to `MOON_SKINS.zine`, so the eight existing consumers keep their current values.
- `MOON_FONTS.editorial` is added for the Empire serif role.
- `packages/moonui/test/skins.test.ts` proves: key parity; the zine↔`MOON_COLORS` bridge; WCAG ratios (`fg/bg`, `fg-muted/bg`, `brand/bg`, `on-brand/brand-2`, `fg/bg-1` ≥ 4.5, `focus/bg` ≥ 3); the property allowlist on the empire block; and that the danger variant reads `var(--danger)`.
- The root `test` script runs the moonui suite, which it previously did not.

## Verification

- `pnpm --filter @moonwitness/moonui test` passes.
- `pnpm --filter @moonwitness/moonui build` emits updated types.
- `pnpm test` reaches the moonui suite.

## Rollback

Remove `MOON_SKINS`, `MOON_FONTS.editorial`, `skins.test.ts` and the root `test` addition. Nothing else depends on them.

## Required report

Commands run, the measured contrast ratios per skin, and the exact key list the parity test asserts.
