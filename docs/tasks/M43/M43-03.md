# M43-03 — Make `apps/empire-web` consume the skin

**EXECUTABLE LEAF, NOT VERIFIED** · Priority P1 · Difficulty D4 · Owner: Empire Web. [TODO](../../../TODO.md) owns status.

## Objective

Remove the app-local pseudo-skin and let the application render through MoonUI role tokens, so the second visual language becomes a property of the design system rather than of one stylesheet.

## Entry gates

- M43-02 is closed: `MOON_SKINS` and `skins.test.ts` pass.
- The five approved WebP assets are unchanged; the private PNG references stay under `docs/` and out of `public/`.

## Scope

- Both root layouts pin `data-skin` on the `<html>` element (`zine` for the entry route family, `empire` for the localized family).
- `data-theme="empire-story"` is removed from `StoryUniverse.tsx`; the `--eol-*` block is deleted; `.su-*` locals alias role tokens and keep all class names intact.
- 139 UI hex values and 13 font shorthands are replaced by role tokens. CSS-drawn artwork (covers, moons, silhouettes, skylines) keeps its own colours.
- `test/token-purity.test.mjs` enforces the palette denylist, the absence of `--eol-` and `data-theme`, and the `data-skin` placement.
- `scripts/check-ui-consistency.mjs` gains the Empire surface and stylesheet, but not its artwork colours.

## Verification

- `pnpm --filter @moonwitness/empire-web test`, `typecheck`, scoped ESLint and `build` pass.
- `node apps/empire-web/test/export-check.mjs` passes: eight localized routes, noindex, five WebP, zero PNG, no `.png` in `out/`.
- `pnpm ui:check` passes.

## Rollback

Restore the `--eol-*` block, the `data-theme` attributes and the previous `globals.css` revision; the default skin is unaffected, so no other app needs a change.

## Required report

Commands run, remaining raw-hex count split into palette versus artwork, the token mapping used, and any visual deviation observed.
