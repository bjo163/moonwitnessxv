**EXECUTABLE LEAF, NOT VERIFIED** · Priority P1 · Difficulty D4 · Owner: release/integration. [TODO](../../../TODO.md) owns status.

## Objective

Prove both skins render correctly and that the Empire application is unchanged in behaviour, then record the release and rollback state.

## Entry gates

- M43-03 is closed with app tests, typecheck, build and export evidence.
- No unrelated working-tree change is included in the release commit.

## Scope

1. Confirm computed `--bg` is `#07060b` on `/` (zine) and `#090b0d` on `/[locale]` (empire).
2. Check `/`, `/id`, `/en`, both `stories` routes, the `angelwithshotgun` readers, both `characters` and both `ggs` routes at 390×844, 768×1024, 1122×1402, 1440×900 and 1920×1080; no horizontal overflow at 1920.
3. Check focus rings, hover, active, disabled, empty and error states in both skins.
4. Confirm `noindex, nofollow`, the security headers and the five WebP responses are unchanged.
5. Record screenshots against the pre-change baseline and list remaining visual deviations.
6. Record the promoted SHA, the redeploy result and the previous production deployment as the rollback target.

## Verification

All checks above must be observed, not inferred. A green build or CI run alone does not close this task.

## Rollback

Promote the previous production deployment in the existing Vercel project. No custom domain, DNS or indexing change is part of this task.

## Required report

Exact commands run, viewport matrix, computed token values per route family, screenshot locations, deployment identifiers and the rollback target.
