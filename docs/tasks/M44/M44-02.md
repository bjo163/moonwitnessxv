# M44-02 — Attach hostnames, certificates and `www` redirects

**OPERATOR TASK, NOT STARTED** · Priority P1 · Difficulty D3 · Owner: release/ops. [TODO](../../../TODO.md) owns status.

## Objective

Bind each hostname in ADR-0016 to its service in Coolify, issue one certificate per host, and make `www` a single-hop redirect — without touching DNS records outside the documented set.

## Entry gates

- M44-01 accepted: the host→service table exists.
- M44-07 decided: Cockpit and the AI Gateway are either gated or intentionally left unattached.

## Scope

| Host | Service | Container port |
|---|---|---|
| `a-l-l-a-h.com`, `www.a-l-l-a-h.com` | empire-web | 3010 |
| `moonwitness.biz.id`, `www.moonwitness.biz.id` | dock | 3001 |
| `hq.moonwitness.biz.id` | headquarters | 3002 |
| `api.moonwitness.biz.id` | arsy | 3000 |
| `orbit.moonwitness.biz.id` | orbit | 3007 |
| `media.moonwitness.biz.id` | echolog | 3006 |
| `skylink.moonwitness.biz.id` (path `/api/v1/webhooks`) | skylink | 3005 |

Never route `db`, `backup`, `sentinel`, `lumen-runtime`. Configure the `www` redirect in Coolify only — nginx keeps `server_name _` and no redirect rules.

## Verification

Per host: domain row shows **READY**, certificate issued by Let's Encrypt, `https://<host>` answers, `http://` upgrades. `www` returns 301 in one hop to the apex.

## Rollback

Detach the domain from the service; Coolify leaves the auto-generated domain working.

## Required report

Host, service, port, certificate state, redirect target and the timestamp of each binding.
