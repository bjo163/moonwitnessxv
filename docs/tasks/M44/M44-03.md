# M44-03 — Make the empire apex canonical and indexable

**IMPLEMENTED, NOT VERIFIED (no commit SHA yet)** · Priority P1 · Difficulty D3 · Owner: Empire Web. [TODO](../../../TODO.md) owns status.

## Objective

Declare `https://a-l-l-a-h.com` as the canonical origin of the static pilot, give every exported route a canonical URL and hreflang pair, and stop the edge from overriding that decision.

## Scope

- `apps/empire-web/src/lib/seo.ts` (**new**): `SITE_ORIGIN`, `LOCALIZED_PATHS`, `canonicalUrl()`, `routeMetadata()`.
- `(entry)/layout.tsx`, `(localized)/[locale]/layout.tsx`: `metadataBase` + `robots: { index: true, follow: true }`.
- Every `page.tsx` under `(localized)/[locale]`: `generateMetadata` returning `routeMetadata(locale, path)`; `(entry)/page.tsx` declares the `/` canonical.
- `src/app/robots.ts`: allow all, `sitemap` and `host` from `SITE_ORIGIN`.
- `src/app/sitemap.ts` (**new**): 23 URLs (entry + 11 routes × 2 locales) with hreflang alternates, no fabricated `lastModified`.
- `apps/empire-web/nginx.conf`: drop `X-Robots-Tag`, add `Strict-Transport-Security "max-age=15552000"` (no `includeSubDomains`, no `preload`).

## Editorial note (required by ADR-0016 §4)

Indexing publishes fiction and draft-labelled editorial copy. The app quotes no scripture — the GGS page renders `RELIGIOUS SOURCE CONTENT WITHHELD` / `SUMBER KEAGAMAAN BELUM DITAMPILKAN` in both locales — so no unverified quotation is published by this change. Remaining editorial/source/rights review stays open as content work, not as a blocker to crawling. Reverting the flip is one commit across the files above plus their tests.

## Verification

`pnpm --filter @moonwitness/empire-web build` emits `sitemap.xml` and `robots.txt`; `node apps/empire-web/test/export-check.mjs` asserts `<meta name="robots" content="index, follow">`, a per-route canonical, 23 sitemap URLs, and a `robots.txt` that allows and names the sitemap.

## Rollback

Revert the commit; the build returns to `disallow: '/'`, `index: false` and the global `X-Robots-Tag`.

## Result (2026-10-29)

Built output verified locally: `robots.txt` (`Allow: /`, `Host`, `Sitemap`), `sitemap.xml` with 23 `<loc>` entries and `xhtml:link` alternates, `<link rel="canonical" href="https://a-l-l-a-h.com/en">` plus `hreflang` pairs. Empire tests 10/10, export-check 6/6 PASS, typecheck clean.
