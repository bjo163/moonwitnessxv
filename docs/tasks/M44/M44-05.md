# M44-05 — Demote the Vercel project to preview-only

**CLOSED 2026-10-29** · Priority P1 · Difficulty D2 · Owner: release/ops. [TODO](../../../TODO.md) owns status. Evidence: [audit §9.5](../../audit/M44-domain-cutover.md#95-host-matrix-observed).

## Objective

Keep the Vercel project useful for reviews while guaranteeing it can never become a second indexable copy of the pilot.

## Scope

- Do **not** attach `a-l-l-a-h.com` or `www.a-l-l-a-h.com` to the Vercel project; the Coolify container is canonical.
- If a custom domain is currently attached there, remove it in Vercel (not in DNS) and leave the `*.vercel.app` aliases.
- Keep `apps/empire-web/vercel.json` exactly as it is: its `X-Robots-Tag: noindex, nofollow` header is now the mechanism that hides previews, because the app itself declares `index`.
- Record in the M44-05 note which hostnames the Vercel project still answers on.

## Verification

`curl -sSI https://<vercel-alias>/en` returns `X-Robots-Tag: noindex, nofollow` while the same build served by Coolify returns `index, follow` in the meta tag. Two different hosts, one indexable.

## Rollback

Re-attach the domain in Vercel only if the Coolify cutover is abandoned; then re-enable the pre-ADR indexing commit as well.

## Required report

- **Project:** `empire-web` (aliases under `bjo163s-projects`), build served by Coolify at `a-l-l-a-h.com`.
- **Aliases still answering:** `a-l-l-a-h-empire-web.vercel.app` and `a-l-l-a-h-empire-web-bjo163s-projects.vercel.app`. Both return `HTTP/1.1 200`, `Server: Vercel`, `X-Robots-Tag: noindex, nofollow` on `/en` (2026-10-29).
- **Custom domains removed:** `a-l-l-a-h.com` and `www.a-l-l-a-h.com` resolve to the Cloudflare edge in front of the Coolify origin and are served by Coolify — `/en` answers with empire-web's nginx headers (`strict-transport-security`, `nosniff`, `DENY`) and `Server: cloudflare`, not Vercel. The apex therefore cannot be bound to the Vercel project at the same time. The Vercel control plane itself was not consulted: this host holds no Vercel token, so "the project lists no custom domain" is inferred from the DNS and origin evidence, not read from Vercel.
- **Header proof:** `vercel.json` keeps `X-Robots-Tag: noindex, nofollow` while the same build on the apex declares `<meta name="robots" content="index, follow">` — two hosts, one indexable.
