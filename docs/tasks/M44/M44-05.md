# M44-05 — Demote the Vercel project to preview-only

**OPERATOR TASK, NOT STARTED** · Priority P1 · Difficulty D2 · Owner: release/ops. [TODO](../../../TODO.md) owns status.

## Objective

Keep the Vercel project useful for reviews while guaranteeing it can never become a second indexable copy of the pilot.

## Scope

- Do **not** attach `a-l-l-a-h.com` or `www.a-l-l-a-h.com` to the Vercel project; the Coolify container is canonical.
- If a custom domain is currently attached there, remove it in Vercel (not in DNS) and leave the `*.vercel.app` aliases.
- Keep `apps/empire-web/vercel.json` exactly as it is: its `X-Robots-Tag: noindex, nofollow` header is now the mechanism that hides previews, because the app itself declares `index`.
- Record in the M44-05 note which hostnames the Vercel project still answers on.

## Verification

`curl -sSI https://<vercel-alias>/en` returns `X-Robots-Tag: noindex, nofollow` while the same build served by Coolify returns `index, follow` in the meta tag. Two different hosts, one indexable.

## Rollback

Re-attach the domain in Vercel only if the Coolify cutover is abandoned; then re-enable the pre-ADR indexing commit as well.

## Required report

Vercel project name, remaining aliases, removed custom domains, and the header proof.
