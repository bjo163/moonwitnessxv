# M44-06 — Wire hostnames into runtime configuration

**IMPLEMENTED, NOT VERIFIED (no commit SHA yet)** · Priority P1 · Difficulty D3 · Owner: platform. [TODO](../../../TODO.md) owns status.

## Objective

Make the running stack agree with the public hostnames: the hub must dial ECHOLOG by service name, the frontends must advertise the public URLs, and CORS must name exactly the browser origins that exist.

## Scope

- `docker-compose.yml`, `arsy` service: `ECHOLOG_URL: ${ECHOLOG_URL:-http://echolog:3006}` with the reason in a comment. Without it the hub falls back to `127.0.0.1:3006` — itself, inside its own container.
- `.env.coolify` (gitignored): `CORS_ORIGIN=https://moonwitness.biz.id,https://orbit.moonwitness.biz.id`, `DOCK_URL=https://moonwitness.biz.id`, `HQ_URL=https://hq.moonwitness.biz.id`, `HQ_COOKIE_SECURE=true`, `TRUST_PROXY=true`.
- SKYLINK: `SKYLINK_TELEGRAM_WEBHOOK_SECRET` set; webhook URL `https://skylink.moonwitness.biz.id/api/v1/webhooks/telegram`.
- Changed 2026-10-29: `RADIO_API_URL` now dials `http://arsy:3000${API_PREFIX}` instead of the `radio` alias. The alias is declared under compose's `default` network, but Coolify attaches every service to its own network, so the alias was never registered where Dock, HQ, Orbit or Sentinel resolve it — the live HQ log showed `getaddrinfo ENOTFOUND radio` and `hq` login fell back to `/login?error=unavailable`. The service name is the only name registered on the network the proxy and the BFFs share.

## Verification

`docker compose --env-file .env.coolify config` resolves `ECHOLOG_URL`, `CORS_ORIGIN`, `DOCK_URL` and `HQ_URL`; `apps/arsy/src/plugins/cors.ts` echoes the list; `pnpm gen:sdk:check` and the compose contract tests still pass.

## Rollback

Revert the compose line; `.env.coolify` is local and revertible by editing.

## Result (2026-10-29)

`ECHOLOG_URL` added to the `arsy` service. `.env.coolify` updated with the public hostnames. `CORS_ORIGIN` deliberately lists only the two browsable origins: Dock and HQ call the hub server-side, and whether ORBIT calls it from the browser is still unconfirmed (ADR-0016 §Known limits).
