# M44-09 — Rollback drill and TTL plan

**OPERATOR TASK, NOT STARTED** · Priority P1 · Difficulty D3 · Owner: release/ops. [TODO](../../../TODO.md) owns status.

## Objective

Make the cutover reversible in minutes, with a rehearsal rather than a promise.

## Scope

1. **Before the cutover:** set every record used by ADR-0016 to `TTL 300`. Do not touch `NS`, `MX`, or any TXT record used for mail.
2. **Keep the old targets alive 48 h:** the Coolify auto-generated domains and the `*.vercel.app` aliases stay attached after the custom domains go live.
3. **Rehearse once:** repoint one record (the safest is `www.a-l-l-a-h.com`) to the previous target, confirm the redirect, then repoint it back. Record the elapsed time.
4. **Documented recovery:**
   - DNS: repoint to the previous target (Coolify auto-domain for the stack, Vercel alias for the pilot).
   - Code: redeploy the last known-good tag (`v2.20.2` is the last release before this milestone).
   - Indexing: one commit reverts `robots.ts`, `sitemap.ts`, both layouts, `nginx.conf` and their tests.
5. **After 48 h of clean operation:** raise the TTL back to a normal value and remove the temporary aliases.

## Verification

The drill is timed and recorded in `docs/audit/M44-domain-cutover.md`, with the exact commands.

## Rollback

There is nothing to roll back: this task produces a procedure and a rehearsal record.

## Required report

Pre-cutover TTLs, the drilled record, time to recovery, and the date the temporary aliases were removed.
