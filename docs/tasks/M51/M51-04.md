## Objective

Adapt the committed MWX-ISP Go protocol pipeline into `apps/isp-radius`; route every durable lookup/write through scoped D00 service calls to ARSY.

## Scope and boundaries

- Reuse reviewed RADIUS, EAP, RadSec and vendor protocol code from the pinned source commit.
- Remove GORM/database/business REST ownership; the runtime owns protocol listeners and bounded in-memory state only.
- Keep RADIUS shared secrets and TLS material in mounted secret files; never log credentials or raw authentication material.

## Acceptance and evidence

- Fake-NAS tests cover accept/reject, unknown NAS/secret, accounting idempotency, RadSec trust/expiry and CoA/Disconnect ACK/NAK/timeout/retry.
- ARSY outage denies new authentication, does not acknowledge unpersisted accounting, and sends no uncommitted session action.
- Go module builds/tests at Go 1.26 and the runtime has truthful liveness/readiness states.
