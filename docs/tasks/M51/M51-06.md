# M51-06 — Build the private ISP operator console

**EXECUTABLE LEAF** · P1/D4 · Depends on M51-03, M37-05 · [TODO status](../../../TODO.md) · [Milestone](../../milestones/M51.md).

## Objective

Build `apps/isp-console` for authorized ISP operators using ARSY server-side BFF calls, D00 sessions/grants and MoonUI.

## Scope and boundaries

- Provide bilingual `id`/`en` views for tenant, customer/service references, RADIUS users/profiles, NAS, sessions, accounting, invoices and registered-target health.
- Use Empire skin tokens, accessible forms/dialogs, keyboard navigation and words for freshness/error states.
- Keep browser bundles free of service keys, NAS secrets and direct database/API credentials; no Dock public route or customer self-service.

## Acceptance and evidence

- Positive UI/API tests cover authorized tenant navigation and safe confirmed session actions; negative tests cover missing/expired session, absent grant, wrong tenant and secret redaction.
- Locale keys have parity; keyboard/focus and reduced-motion behavior follow Master Design.

## Verification and rollback

Run app typecheck/tests and focused accessibility checks. Roll back the new app registration and workspace without changing canonical D20 data.

Follow the [AI execution contract](../../planning/AI_EXECUTION_CONTRACT.md); TODO alone records completion.
